# 视角地图 Perspective Map

> 遇到一件事时，先把它的各个方面摊开，再去问 AI。

视角地图是一个开源的思考框架工具。它不提供答案，而是帮助你在向 AI 提问之前，先看到一件事还牵涉哪些方面、还应该问什么。

[English](README.md) · 简体中文 · 作者：Fantasia Skadi Candy，与 Claude 共同制作 · 许可证：MIT · 当前版本：v0.1.0

---

## 为什么做这个工具

当我们遇到一件事，向 AI 提问时，往往只会问到它的一个侧面，而回答也就停在那个侧面上。一个不熟悉相关领域的人，很难知道还有哪些关键的方面被忽略了，甚至不知道该问什么、怎么问。

视角地图想解决的，正是这个问题：在提问之前，先把地图展开。这件事里有哪些是确知的事实，哪些只是推测？牵涉哪些人？原因在个人、人际关系、制度与结构上分别是什么？不同领域会怎样看？有哪些价值上的问题需要考虑？有哪些做法，各自的代价是什么，能不能撤回？

工具本身不包含任何领域知识，也不预设任何人的价值观。它只提供一套思考的步骤和提示词，具体内容由你自己选择接入的 AI 来生成。

## 它能做什么，不能做什么

**它能做的：**

- 把一件事拆解为若干个方面，生成一段结构清晰的提示词；
- 让你选择希望从哪些领域来看，并要求 AI 对每个领域内的不同观点作公平的陈述；
- 在你愿意时，对照你自己写下的价值原则来分析，同时仍然呈现其他观点；
- 提醒 AI 说明自己不确定的地方，并在涉及健康、法律、财务、人身安全时，建议你寻求专业帮助。

**它不能做的：**

- 它不替你做决定。最后一步永远是写下你自己的判断；
- 它不保证 AI 的回答正确。AI 可能出错，甚至编造信息，重要的判断请核实来源；
- 它不能代替医生、律师、心理咨询师等专业人士，也不能代替紧急求助。

## 如何使用

### 方式一：在线使用

打开项目的网页地址（启用 GitHub Pages 后为 `https://candifantasia.github.io/perspective-map/`），无需安装。

### 方式二：本地使用

下载 `perspective-map v0.1.0.html`，用浏览器直接打开即可。

### 切换语言

页面右上角可以在 English 与简体中文之间切换，生成的提示词也会随之切换。

### 使用步骤

1. **发生了什么**：描述这件事。尽量写下事实，也可以写下你的感受和担心。请不要写入他人的隐私信息，比如真实姓名、电话或证件号。
2. **想从哪些领域看**：从心理学、人际关系、法律、经济学等领域中勾选。不选的话，由 AI 挑选最相关的两到三个。
3. **分析哪些方面**：默认包含八个方面，可以按需要取消。
4. **你自己的价值观（可选）**：如果你有自己的原则，可以写下来。不写的话，分析保持中立。
5. **获得分析**：
   - **复制提示词**：把生成的提示词复制到任何 AI 对话中。不需要任何账号或密钥。
   - **直接调用 AI**：填入你自己的服务地址、模型名称和 API 密钥，在页面中直接获得回答。
6. **读完以后，你怎么看**：写下你自己的判断，尤其是你不同意 AI 的地方。

### 关于"直接调用 AI"

目前支持两类接口：

| 接口类型 | 适用于 | 默认地址 |
| --- | --- | --- |
| OpenAI 兼容 | 多数大模型服务商；本地运行的 Ollama 等 | `https://api.openai.com/v1` |
| Anthropic | Claude 系列模型 | `https://api.anthropic.com` |

请注意：

- 有些服务商不允许网页直接调用其接口。如果连接失败，请使用"复制提示词"。
- 使用本地模型（例如 Ollama，地址一般为 `http://localhost:11434/v1`）时，可以完全离线运行。如果出现跨域错误，需要在 Ollama 的设置中允许该网页的来源，具体方法请参阅 Ollama 的官方文档。

## 分析的八个方面

| 方面 | 内容 |
| --- | --- |
| 事实与信息缺口 | 区分已知事实、推测与情绪；列出做判断前最需要补充的信息 |
| 相关的人 | 牵涉哪些人或群体，各自可能的立场、利益和感受 |
| 原因的层次 | 个人、人际关系、制度与结构三个层面的原因 |
| 领域视角 | 所选领域会关注什么；每个领域内至少两种不同观点，并公平陈述 |
| 价值考量 | 以问题的形式列出涉及的价值问题，并说明几种伦理视角会如何看待 |
| 可选的行动与代价 | 几种做法各自的代价、风险，以及能否撤回 |
| 不确定与边界 | 哪里可能出错；何时应当寻求专业帮助 |
| 留给你的问题 | 两到三个问题，请你对照自己的直觉思考 |

完整的提示词文本见 [`framework/zh-CN/`](framework/zh-CN/) 文件夹。

## 设计原则

1. **镜子，而不是神谕。** 工具帮助你看见，而不替你决定。最后一步永远交还给你自己。
2. **透明，而不是假装中立。** 任何框架都包含取舍。比如，"原因有多个层次"本身就是一种预设。我们把这些预设公开写出来，让你知道自己正透过什么样的镜头看问题。
3. **公平地陈述不同观点。** 对每个领域，至少呈现两种不同的观点，并以其支持者会认可的方式来陈述，包括你不赞同的观点。
4. **价值观可以替换。** 工具不内置任何人的价值观。你可以写下自己的原则，也可以不写。
5. **知道自己的边界。** 要求 AI 说明不确定之处；涉及健康、法律、财务、人身安全或心理危机时，建议寻求专业帮助。
6. **普惠。** 只需一个网页，不用安装；不需要账号就能使用；也可以接入本地模型完全离线运行。

## 隐私与安全

- 这个网页没有服务器，你填写的内容不会被发送给本项目。
- 只有在你选择"直接调用 AI"时，提示词才会被发送到你自己填写的服务地址。
- API 密钥只保存在当前页面中，刷新即清除，不会被存储。
- "你怎么看"一栏的内容，只保存在你这台设备的浏览器里。
- 请不要在描述中写入他人的隐私信息。
