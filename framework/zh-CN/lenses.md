| 领域 | 关注点 |
| --- | --- |
| 心理学 | 感受、动机、认知偏差 |
| 人际关系 | 信任、边界、沟通 |
| 社会学 | 群体、规范、社会结构 |
| 经济学 | 激励、成本、资源分配 |
| 法律 | 权利、义务、规则与风险 |
| 政治与公共政策 | 权力、制度、公共利益 |
