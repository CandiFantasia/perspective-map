# 设计原则与框架的预设

## 设计原则

1. **镜子，而不是神谕。** 工具帮助用户看见，而不替用户决定。
2. **透明，而不是假装中立。** 公开写出框架自身的预设。
3. **公平地陈述不同观点。** 以其支持者会认可的方式陈述，包括我们不赞同的观点。
4. **价值观可以替换。** 不内置任何人的价值观。
5. **知道自己的边界。** 说明不确定之处，必要时建议寻求专业帮助。
6. **普惠。** 一个网页，无需安装，无需账号，可完全离线。

## 框架的预设

任何框架都有取舍。这套框架预设了：

- 原因有多个层次：个人、人际关系、制度与结构；
- 价值问题适合以问题的形式提出，而不是由工具给出答案；
- 每个领域内部通常存在值得呈现的不同观点；
- 行动是否可以撤回，是评估行动时值得特别关注的一点；
- 用户自己的判断，应当是整个过程的最后一步。

如果你认为这些预设不合适，可以直接修改提示词，也欢迎在 Issues 中讨论。
