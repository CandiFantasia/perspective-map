# Perspective Map

> When something happens, lay out all its sides before you ask an AI.

Perspective Map is an open-source thinking framework. It does not give answers. Before you ask an AI about a situation, it helps you see what else the situation involves and what else you should ask.

## Why this tool exists

When something happens and we ask an AI about it, we usually ask about only one side of it, and the answer stays on that side. Someone who doesn't know the relevant fields can hardly tell which important aspects have been left out, or even what to ask and how to ask it.

Perspective Map is meant to help with exactly that: open the map before you ask. Which parts of the situation are known facts, and which are only guesses? Who is involved? What are the causes at the personal level, in relationships, and in institutions and social structures? How would different fields see it? What value questions does it raise? What could you do, what would each option cost, and could it be undone?

The tool itself contains no domain knowledge and no one's personal values. It only provides a set of thinking steps and prompts. The content is generated by whichever AI you choose to use.

## What it can and cannot do

**It can:**

- break a situation down into several aspects and build a clearly structured prompt;
- let you choose which fields to look from, and ask the AI to state the different views within each field fairly;
- if you wish, analyze the situation against principles you write down yourself, while still presenting other views;
- remind the AI to say where it is unsure, and to suggest professional help when health, law, money or personal safety is involved.

**It cannot:**

- make the decision for you. The last step is always to write down your own judgment;
- guarantee that the AI is right. AI can be wrong and can even make things up, so check sources before important decisions;
- replace doctors, lawyers, counsellors or other professionals, or replace emergency help.

## How to use it

### Option 1: online

Open the project's web address https://candifantasia.github.io/perspective-map/. Nothing to install.

### Option 2: locally

Download perspective-map v0.1.0.html(https://github.com/CandiFantasia/perspective-map/releases/tag/perspective-map.v0.1.0) and open it in a browser.

### Language

Use the switch in the top-right corner to choose English or Simplified Chinese. The generated prompt switches language too. English is the default.

### Steps

1. **What happened**: describe the situation. Write down the facts as best you can; you can include your feelings and worries too. Please leave out other people's private details, such as real names, phone numbers or ID numbers.
2. **Which fields to look from**: choose from psychology, relationships, law, economics and other fields. If you choose none, the AI picks the two or three most relevant ones.
3. **Which aspects to analyze**: eight aspects are included by default; untick any you don't need.
4. **Your own values (optional)**: if you have principles of your own, write them down. If you don't, the analysis stays neutral.
5. **Get the analysis**:
   - **Copy prompt**: copy the generated prompt into any AI chat. No account or key needed.
   - **Ask an AI directly**: enter your own service address, model name and API key, and get the answer on the page.
6. **After reading: what do you think?** Write down your own judgment, especially where you disagree with the AI.

### About "Ask an AI directly"

Two kinds of API are supported:

| API type | For | Default address |
| --- | --- | --- |
| OpenAI-compatible | Most model providers; locally run models such as Ollama | `https://api.openai.com/v1` |
| Anthropic | Claude models | `https://api.anthropic.com` |

Please note:

- Some providers don't allow their API to be called directly from a web page. If the connection fails, use "Copy prompt".
- With a local model (for example Ollama, usually at `http://localhost:11434/v1`) the tool can run fully offline. If you see a cross-origin error, allow the page's origin in Ollama's settings; see Ollama's official documentation for how.

## The eight aspects

| Aspect | What it covers |
| --- | --- |
| Facts and missing information | Separate known facts, guesses and feelings; list what is most needed before judging |
| People involved | Who is involved, and their likely positions, interests and feelings |
| Layers of causes | Causes at the personal, relational, and institutional or structural level |
| Field perspectives | What each chosen field looks at; at least two views within each field, stated fairly |
| Value questions | The value questions involved, posed as questions, and how several ethical perspectives would see them |
| Options and their costs | Possible actions, their costs and risks, and whether they can be undone |
| Uncertainty and limits | Where the analysis may be wrong; when to seek professional help |
| Questions for you | Two or three questions to check against your own intuition |

The full prompt text is in [`framework/en/`](framework/en/).

## Design principles

1. **A mirror, not an oracle.** The tool helps you see; it does not decide for you. The last step always comes back to you.
2. **Transparent, rather than pretending to be neutral.** Every framework involves trade-offs. "Causes come in layers", for instance, is itself an assumption. We write these assumptions down openly, so you know what lens you are looking through.
3. **State different views fairly.** For each field, present at least two views, each stated in a way its own supporters would accept, including views we disagree with.
4. **Values are replaceable.** The tool has no one's values built in. You can write down your own principles, or not.
5. **Know the limits.** The AI is asked to say where it is unsure, and to suggest professional help for health, legal, financial, safety or mental health matters.
6. **Accessible to everyone.** A single web page, nothing to install, no account required, and it can run fully offline with a local model.

## Privacy and safety

- The page has no server. Nothing you write is sent to this project.
- Only when you choose "Ask an AI directly" is the prompt sent, and only to the service address you enter yourself.
- Your API key is kept in the page's memory only. It is cleared when you reload and is never stored.
- What you write under "After reading: what do you think?" is saved only in this device's browser.
- Please don't include other people's private details in your description.
