# Changelog 更新日志

Version numbers follow the format MAJOR.MINOR.PATCH. 版本号遵循"主版本.次版本.修订号"的格式。

## v0.1.0 — 2026-10-25

First public version. 首个公开版本。

- A single web page, nothing to install 单个网页即可使用，无需安装
- English (default) and Simplified Chinese interface and prompts 英文（默认）与简体中文的界面和提示词
- Eight aspects of analysis, each optional 八个分析方面，可按需勾选
- Twelve fields to choose from 十二个可选领域
- Optional personal value principles 可选填写自己的价值原则
- Two ways to use it: copy the prompt, or connect your own API (OpenAI-compatible or Anthropic) 两种使用方式：复制提示词；接入自己的 API（OpenAI 兼容接口、Anthropic 接口）
- The framework's own assumptions stated openly 公开说明框架自身的预设
